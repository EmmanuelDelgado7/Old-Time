# Old Time

Old Time es un sitio web dedicado a la relojería vintage y de colección.

## Descripción

Este proyecto fue desarrollado utilizando HTML, CSS, Bootstrap y JavaScript. Su objetivo es presentar un catálogo de relojes clásicos con una interfaz elegante e inspirada en la relojería tradicional.

## Características

- Página de inicio con presentación de la marca.
- Catálogo de relojes con filtros por marcas.
- Página de detalle del producto.
- Página sobre nosotros con formulario de contacto.
- Diseño responsive mediante Bootstrap.
- Estilo visual inspirado en la relojería vintage.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
