# OldTime Backend

## Descripción General

OldTime es un proyecto Full Stack orientado a la compra y venta de relojes vintage y de colección.

En la primera entrega se desarrolló el frontend utilizando HTML, CSS, Bootstrap y JavaScript.

En esta segunda entrega se desarrolló la estructura inicial del backend utilizando Node.js, Express.js, MongoDB y Mongoose. Además, se implementaron los modelos de datos, la organización del proyecto mediante arquitectura por carpetas, los controladores y las rutas CRUD necesarias para gestionar usuarios y productos.

---

## Funcionalidades

- Configuración del servidor con Express.js.
- Organización del proyecto mediante arquitectura por carpetas.
- Configuración de variables de entorno con Dotenv.
- Conexión a MongoDB Atlas mediante Mongoose.
- Modelo de Usuario.
- Modelo de Producto.
- Controladores para usuarios y productos.
- Rutas CRUD para usuarios y productos.
- Endpoint de prueba para verificar el funcionamiento del servidor.
- Base preparada para la futura integración con el frontend.

## Instalación

### Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

### Entrar a la carpeta del proyecto

```bash
cd oldtime-backend
```

### Instalar dependencias

```bash
pnpm install
```

### Configurar las variables de entorno

```env
PORT=3000
URI_MONGO=tu_cadena_de_conexion
```

### Ejecutar el proyecto

```bash
pnpm dev
```

o

```bash
pnpm start
```
